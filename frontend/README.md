# Web3 助手前端

依据产品原型 `web3-product/prototype/v1.html` 调整，使用暗色桌面布局（最小宽度 1120px）。数据来自真实服务接口，知识库显示为规划中。

## 本地运行

复制 `.env.example` 为 `.env` 并配置 Reown 的公开 projectId，然后运行 `npm ci` 和 `npm run dev`。基础服务启动在 8000，Agent 服务启动在 8001，前端启动在 5173。

开发代理将 `/api/v1/chat` 转发到 Agent，其余 `/api` 转发到基础服务。两个健康探针通过 `/foundation-health` 和 `/agent-health` 转发；正式部署配置对应环境变量或反向代理。

## 页面与流程

- 对话：登录后打开本人固定会话、读取历史、提交问题与幂等 ID，通过 SSE 接收完整快照。支持重连、重试、停止、清空。资产卡片通过结果 ID 向基础服务读取真实余额。
- 代币余额：选择网络、精确币种和 USD/CNY，创建查询结果，再读取结果卡片。不调用模型，仅查询已登记代币；失败网络和未计价资产分别提示。
- 行情：无需登录，按网络读取公开报价，可筛选币种。点击币种查看单币详情，支持 USD/CNY、七日变化和汇率日期；数据源缺失字段显示为破折号。
- 服务与接口：展示实际接口目录。侧栏探针仅表示 HTTP 服务存活，不代表数据库、模型或 RPC 可用。
- 会话与设置：展示钱包身份、凭证到期、上下文保留时间和部署配置的模型窗口。切换在线模型需要确认元数据外发；服务器拒绝生成期间的切换。
- 风险、质押、概览：保留既有独立业务接口与页面。
- 知识库：尚未接入，不提供模拟上传和问答。

连接钱包不等于登录，必须签名验证。访问凭证到期自动续期，刷新凭证失效后要求重新登录。钱包切换清除旧登录与私有查询缓存。前端不作为身份或权限的可信来源。

## 代码入口

`router/index.tsx` 注册路由；`components/AppLayout.tsx` 提供公共外壳；`components/RequireAuth.tsx` 提供页面内登录门槛。`api/client.ts` 与 `api/session.ts` 统一响应、鉴权和续期；`api/chat.ts` 处理 Agent 请求与 SSE；`api/resources.ts` 处理网络目录、资产查询和模型设置。`views/Copilot.tsx` 维护页面状态，服务器仍是会话状态的权威来源。

`npm test` 检查 API/SSE 契约；`npm run lint` 检查代码；`npm run build` 检查类型和构建。真实钱包签名、模型和 RPC 的端到端链路需要启动服务后在浏览器验证。


## 原型补全

页面按原型保留统计区、结果明细区、签名原文预览、模型选择列表、知识库列表和引用样式、运维占位区域。原型的演示数据不作为真实数据展示。全市场指标、准确率、上下文用量、P95 尚无对应统计接口，原位显示未接入；工具轨迹展示真实结果引用元数据，不伪造完整执行耗时。

离线历史仅使用当前标签页的 sessionStorage，保存展示消息（包括用户原文）和结果引用，不保存真实资产结果。登录失效时标明本地离线缓存，不调用受保护历史或余额接口；主动退出、钱包切换和登录不同钱包会删除缓存。网络导致的续期故障保留身份，界面提示重试；凭证被明确拒绝才清除登录态。

用户展示原文与模型安全输入分开保存；展示缓存不作为模型上下文。

资产明细中的占比是后端返回的链内占比，不冒充多链总估值占比。金额展示保留后端十进制字符串，CNY 仅按服务端汇率换算。单链重试会查询该链；需要覆盖全部网络时重新选择全部网络查询。


## 动态接口目录

服务与接口页面分别读取基础服务、Agent 服务的 `/openapi.json`，由服务文档生成接口路径、方法、中文用途、标签分组与鉴权说明。目录不发送用户凭证，不执行文档内的业务接口；一个服务不可用时另一目录仍可展示。刷新失败且已有缓存时明确标记旧目录。正式部署可配置 `VITE_FOUNDATION_OPENAPI_URL`、`VITE_AGENT_OPENAPI_URL`，跨域读取需后端允许前端源，或提供同源代理。

接口新增、删除、修改后刷新目录即可反映，无需改前端数组。接口注册不等于实时健康，P95、越权拦截率仍显示未接入。
